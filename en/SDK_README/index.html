    EvoSpikeNet Python SDK

    [!NOTE] For the latest implementation status, please refer to Functional Implementation Status (Remaining Functionality).

    EvoSpikeNet Python SDK is a high-level API client for interacting with the EvoSpikeNet distributed brain simulation system. Features such as text generation, distributed brain simulation, spatial cognitive processing (Feature 13), and artifact management are available with simple Python code.

    Last updated: 2026-05-22 🎯 Added RAG v2 SDK sample and operational guidance

    DevicePlugin development (new)

    • Guide: SDK Device Plugin Guide
    • Template sample: examples/sdk/programs/device_plugin_template.py
    • IBM Runtime demo: examples/sdk/programs/ibm_quantum_runtime_demo.py
    • IBM NeuroChip demo: examples/sdk/programs/ibm_neurochip_demo.py
    • VQE layer demo: examples/sdk/programs/vqe_neuron_layer_demo.py
    • Loihi Brain2Loihi demo: examples/sdk/programs/loihi_brain2loihi_demo.py

    Run:

    python examples/sdk/programs/device_plugin_template.py
python examples/sdk/programs/ibm_neurochip_demo.py
python examples/sdk/programs/vqe_neuron_layer_demo.py
python examples/sdk/programs/loihi_brain2loihi_demo.py

    Minimal IBM Runtime connectivity check:

    pip install -e ".[quantum]"
export QISKIT_IBM_TOKEN=your_token
python examples/sdk/programs/ibm_quantum_runtime_demo.py

    Notes:

    • Without credentials or runtime connectivity, the demo prints a structured fallback such as {"ok": false, "reason": "runtime_not_connected"}.
    • With valid connectivity, it prints plugin capabilities plus sampler counts/probabilities and an estimator expectation value.
    • See the SDK Device Plugin Guide and Functional Implementation Status for the full workflow and current scope.
    • For Loihi simulator details, see SDK Loihi Brain2Loihi Execution Guide.

    RAG v2 SDK (new)

    • Search: rag_v2_search()
    • Feedback recording: rag_v2_feedback()
    • Preprocessing health check: rag_v2_preprocessing_health()
    • Sample: examples/sdk/programs/rag_v2_sdk_demo.py

    Run:

    python examples/sdk/programs/rag_v2_sdk_demo.py --query "EV-2024-001 の進捗会議"
python examples/sdk/programs/rag_v2_sdk_demo.py --rating 5

    This sample targets the main API endpoints /api/v2/rag/search, /api/v2/rag/feedback, and /api/v2/rag/preprocessing/health.

    Dense Chrono-Spike LM training sample (added)

    • Sample: examples/sdk/programs/llm_train_with_sdk.py
    • Goal: download dataset artifacts, submit best-effort training jobs, and optionally join federated sessions
    • Current safe defaults: stable_baseline + hard-spike parity on + continuous relaxation off

    Run:

    cd EvoSpikeNet-Core
python examples/sdk/programs/llm_train_with_sdk.py \
  --base-url http://localhost:8000 \
  --out-dir ./downloaded_datasets \
  --train \
  --convergence-profile stable_baseline \
  --force-hard-spike-parity \
  --reward-mode ema_delta

    Notes:

    • Training endpoints differ by deployment, so the script tries multiple known paths (/train, /api/train, etc.) in best-effort order.
    • If your environment uses a custom route, pass --train-endpoint multiple times.
    • The payload includes env_overrides, allowing server-side training backends to consume EVOSPIKENET_* convergence controls.

response = client.submit_prompt(
    prompt="この画像を分析してください",
    image_path="./brain_scan.jpg"
)

# Simulation status monitoring
status = client.get_simulation_status()
print(f"Active nodes: {status['active_nodes']}")

    ### Artifact Management

```python
# Create session
session = client.create_log_session("実験セッション")

# model upload
with open('model.pkl', 'rb') as f:
    client.upload_artifact(
        session_id=session['session_id'],
        artifact_type="model",
        name="trained_model",
        file=io.BytesIO(f.read())
    )

# Artifact list
artifacts = client.list_artifacts(artifact_type="model")

# download
client.download_artifact(artifact_id, "downloaded_model.pkl")

    Advanced features

# consensus
