    EvoSpikeNet Python SDK

    [!NOTE] 最新の実装状況は 機能実装ステータス (Remaining Functionality) を参照してください。

    EvoSpikeNet Python SDK は、EvoSpikeNet分散脳シミュレーションシステムと対話するための高レベルAPIクライアントです。テキスト生成、分散脳シミュレーション、空間認知処理（Feature 13）、アーティファクト管理などの機能を、シンプルなPythonコードで利用できます。

    最終更新日: 2026-05-22 🎯 RAG v2 SDK サンプルと運用導線を追加

    共通QUBO問題生成SDK（追加）

    • ガイド: SDK 共通QUBO問題生成ガイド
    • 実道路・空域・動的禁止条件の仕様: 量子アニーリング前処理・共通問題生成仕様
    • オフラインサンプル: examples/sdk/programs/road_qubo_generation_demo.py
    cd EvoSpikeNet-Core
python3.10 examples/sdk/programs/road_qubo_generation_demo.py

    道路の実データ取得には任意依存のOSMnxを導入します。

    pip install -e '.[road]'

    • IBM NeuroChip デモ: examples/sdk/programs/ibm_neurochip_demo.py

    IBM Runtime の最小疎通確認:

    pip install -e ".[quantum]"
export QISKIT_IBM_TOKEN=your_token
python examples/sdk/programs/ibm_quantum_runtime_demo.py

    補足:

    • 認証情報や Runtime 接続がない場合、デモは {"ok": false, "reason": "runtime_not_connected"} のような構造化フォールバックを表示します。
    • 接続に成功した場合、plugin capabilities に加えて sampler の counts/probabilities と estimator の expectation を表示します。
    • 詳細は SDKデバイスプラグイン開発ガイド と 機能実装ステータス を参照してください。
    • Loihi simulator の詳細は SDK Loihi Brain2Loihi 実行ガイド を参照してください。

    RAG v2 SDK（新規）

    • 検索: rag_v2_search()

    このサンプルはメイン API の /api/v2/rag/search、/api/v2/rag/feedback、/api/v2/rag/preprocessing/health を対象にしています。

    Dense Chrono-Spike LM 学習サンプル（追加）

    • サンプル: examples/sdk/programs/llm_train_with_sdk.py
    • 目的: データセット artifact の取得、best-effort な学習ジョブ投入、必要に応じた federated join
    • 現行の安全デフォルト: stable_baseline + hard-spike parity on + continuous relaxation off

    実行例:

    cd EvoSpikeNet-Core
python examples/sdk/programs/llm_train_with_sdk.py \
  --base-url http://localhost:8000 \
  --out-dir ./downloaded_datasets \
  --train \
  --convergence-profile stable_baseline \
  --force-hard-spike-parity \
  --reward-mode ema_delta

    補足:

    • 学習エンドポイントは環境差分があるため、/train など複数パスへ順にPOSTする best-effort 実装です。
    • カスタム経路が必要な場合は --train-endpoint を複数回指定できます。
    • payload には env_overrides も含めるため、EVOSPIKENET_* 系のサーバー実装に対して収束設定を伝搬できます。

    • Python 3.8+
    • 4GB RAM（推奨8GB+）
    • インターネット接続（APIサーバーアクセス用）

    基本インストール

    # プロジェクトルートから
pip install -e .

    オプション機能のインストール

    # Jupyter Notebook統合
pip install -e ".[jupyter]"

# 非同期処理
pip install -e ".[async]"

# WebSocket通信
pip install -e ".[websocket]"

# 全てのオプション
pip install -e ".[all]"

    Dockerを使用したインストール

    # Dockerイメージビルド
docker build -t evospikenet-sdk .

# コンテナ実行
docker run -it evospikenet-sdk
